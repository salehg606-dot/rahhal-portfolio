Power BI dashboards

Sales performance, customer behavior, destination trends and operational efficiency, built on cleaned Power Query datasets.

Illustrative mock-up with sample data.

Data model

Seven relational tables linked by keys (PK = primary key, FK = foreign key).

Customers

PK customer_id

full_name, city, segment

signup_date

Bookings

PK booking_id

FK customer_id, destination_id, package_id

booking_date, nights, total_amount, status, channel

Destinations

PK destination_id

destination_name, region, season

Packages

PK package_id

FK destination_id

package_type, base_price

Payments

PK payment_id

FK booking_id

method, paid_amount, paid_date

Reviews

PK review_id

FK booking_id

rating, review_date

Support_Tickets

PK ticket_id

FK booking_id

issue_type, opened_at, resolved_at

SQL queries

Retrieval, filtering and analysis. Four of the 24+ queries.
